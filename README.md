## Jalankan lokal
Cukup buka `index.html`, atau jalankan server lokal:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000`.

## Deploy ke GitHub Pages
1. Buat repository baru, misalnya `daryel-portfolio`.
2. Upload seluruh isi folder ini ke branch `main`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
6. Setelah beberapa menit, GitHub akan memberi URL portfolio publik.
